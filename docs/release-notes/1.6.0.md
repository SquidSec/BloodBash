## Task-list query engine fixes

Three defects in the native Cypher evaluator broke `.tasks` queries that work
under Neo4j. Each is fixed, with tests.

| Defect | Symptom | Fix |
|--------|---------|-----|
| Scientific notation rejected | Time windows such as `5.184e+6` failed to tokenize | Number literals accept exponents |
| List values as grouping keys | `labels(t)` and `collect(x)` raised `unhashable type: 'list'` | Grouping builds a hashable key; the row keeps the real list value |
| `datetime()` returned null | `datetime().epochSeconds` was `None`, so window predicates matched nothing | `datetime()` returns the current time, as in Cypher |

Effect on PlumHound's own task files: **358 of 360 queries now execute**.

```bash
./bloodbash-linux-x64 /path/to/sharphound --tasks ./my-list.tasks --tasks-out ./reports
./bloodbash-linux-x64 --tasks-validate ./my-list.tasks
./bloodbash-linux-x64 --tasks-list
```

## Install

```bash
# Linux
chmod +x bloodbash-linux-x64
./bloodbash-linux-x64 /path/to/sharphound --all --fast
```

```powershell
# Windows
.\bloodbash-windows-x64.exe C:\path\to\sharphound --all --fast
```

No Python install required.
